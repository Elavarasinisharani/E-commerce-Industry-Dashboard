# 🛒 Amazon Sales Performance Dashboard

## 📌 Project Overview
This project focuses on analyzing Amazon sales data using a dataset sourced from Kaggle (6500 rows). The goal is to extract meaningful insights by performing data cleaning, transformation, and visualization.

The dashboard helps in understanding key metrics such as sales trends, customer behavior, product performance, and regional analysis.

## 🎯 Problem Statement
E-commerce platforms like Amazon generate large volumes of data. Without proper analysis, it becomes difficult to:

- Track sales performance across categories
- Understand customer purchasing behavior
- Analyze the impact of discounts on sales
- Identify high-performing products and regions
- Make data-driven business decisions

This project solves these challenges by building an interactive Power BI dashboard. 

## 🚀 Importance of the Project
- Enables data-driven decision making
- Helps identify top-performing products and regions
- Analyzes customer preferences and behavior
- Evaluates discount effectiveness
- Supports business growth and strategy planning

## 🔄 Data Processing Workflow
1. Data Collection:
Imported dataset from Kaggle

2. Data Cleaning (Excel):
Removed null values
Eliminated duplicates
Standardized formats
Fixed inconsistencies

3. Data Transformation (Power BI - PQE):
Data type corrections
Column transformations
Created calculated columns
Applied business logic

4. Dashboard Development:
KPIs (Total Orders, Revenue, Avg Rating, AOV)
Visualizations (Bar, Line, Map, Donut, Pie)
Filters & Slicers 

## 📊 Dashboard Visualizations
- 📊 Bar Chart → Product Category Performance
- 📈 Line Chart → Avg Rating by product_category
- 🗺️ Map → Regional Sales Distribution
- 🍩 Donut Chart → Total revenue by product category
- 🥧 Pie Chart → Total Orders by customer_region

## 📈 Key Insights from Dashboard
- Certain categories drive higher sales volume
- Regional performance varies significantly
- Discounts influence customer purchasing behavior
- High ratings do not always correlate with high sales
- Customer preferences differ across regions and payment methods

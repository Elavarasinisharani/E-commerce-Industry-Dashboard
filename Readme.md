# 🛒 Amazon Sales Performance Dashboard

## 📌 Project Overview
This project focuses on analyzing Amazon sales data using a dataset sourced from Kaggle (6000+ rows). The goal is to extract meaningful insights by performing data cleaning, transformation, and visualization.

## 🎯 Problem Statement
- Track sales performance across categories  
- Understand customer purchasing behavior  
- Analyze discount impact  
- Identify top-performing products and regions  

## 🚀 Importance of the Project
- Enables data-driven decisions  
- Improves business strategy  
- Analyzes customer behavior  

## 📊 Dataset Details
- Source: Kaggle  
- Records: 6000+  

## 🛠️ Tools Used
- Advanced Excel  
- Microsoft Power BI  
- Power Query Editor  

## 🔄 Workflow
1. Data Cleaning (Excel)  
2. Data Transformation (Power BI - PQE)  
3. Dashboard Creation  

## 📊 Visualizations
- Bar Chart  
- Line Chart  
- Map  
- Donut Chart  
- Pie Chart  

## 📈 Insights
- Regional sales variation  
- Discount impact  
- Customer behavior trends
